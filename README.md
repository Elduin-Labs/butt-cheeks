# Butt Cheeks

<img src="src/main/resources/assets/icon.png" width="128" align="right">

A silly mod by Elduin. It adds one squishy, peach-colored block that bounces you
like a slime block.

Craft it with a slime block, a pink dye and an orange dye. Place it, jump on it, boing!

Works with Minecraft 1.21.11 and 26.2 on Fabric.
